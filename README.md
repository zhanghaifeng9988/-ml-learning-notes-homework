# 中文版机器学习-笔记与作业
基于 Alexey Grigorev 的 Machine Learning Zoomcamp / ML Bookcamp 课程，完整的中文学习记录。

# 项目简介
这个仓库是我学习 Alexey Grigorev 机器学习课程的全过程记录。课程原本是英文视频和英文文档，通过完整的课程学习，我把它完整翻整理成了中文学习过程全记录笔记，
同时完成所有作业和项目。

# 包含内容：
- 全部课程模块的中文笔记（涵盖numpy pandas 矩阵基础，线性回归、逻辑回归、分类、评估指标、树、随机森林、深度学习、部署、aws的serverless、K8S等）

- 每个模块对应的作业代码

- 1–2 个完整的端到端项目
